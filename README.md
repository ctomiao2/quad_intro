## 字段说明

长表与宽表通用字段：

| 字段 | 含义 | 单位/格式 |
| --- | --- | --- |
| code | 标的代码 | 如 513310.SH / 159937.SZ |
| date | 交易日 | YYYYMMDD 整数串 |
| open / high / low / close | 当日开高低收 | 元 |
| volume | 成交量 | 股（指数为手/单位见下） |
| amount | 成交额 | 元（指数为 0 或缺失，见坑点） |
| adj_open/adj_high/adj_low/adj_close | 前复权价 | 元，仅单只宽表有 |

`etf_pool.csv` 额外字段：total_shares/float_shares（总/流通份额）、price_limit（涨跌停幅度）、disabled（1=当前策略禁用）。

## 前复权说明

ETF 会拆分/合股，原始价在拆分日会断崖（例：512800 于 20250707 1 拆 2，价格从 1.74 直接变 0.88）。
宽表里的 `adj_*` 列按以下规则生成，与 quad 策略层 `StrategyETFBase.build_adjusted_prices` 完全一致：

```python
cum = product(ratio for events where date < event.date)
adj_price = raw_price / cum
```

即把历史价格折算到「最新」价格尺度，成交量/成交额不做调整。做收益率、均线、动量类因子时**一律用 adj 列**，否则拆分日会出现 -50% 的假暴跌。

## 已知坑点（教程里务必处理）

1. **各标的上市时间不同**：最早 2016-11，最晚 563230 只有 2025-09 起的数据。做全池截面因子时必须按日期取交集/前向填充，不能假设矩阵对齐。
2. **拆分断崖**：见上节，必须用 adj 列。当前池有拆分的：159320(3.0)、512000(2.0)、512480(2.0)、512800(2.0)、515050(3.0)，详见 adj_factors.json。
3. **个别标的末尾缺日**：512480 / 161129 / 159915 最后一天为 20261028，其余到 20261030，属于数据源当日缺失，不是停牌。
4. **深证指数成交额为 0**：399001/399006 的 amount 列在原数据里就是 0，只有 volume 可用；上证 000001 的 amount 正常。
5. **深证指数滞后一天**：导出时 399001/399006 只到 20261029，上证到 20261030，源数据本身如此。
6. **价格未考虑分红**：只有拆分复权，没有现金分红复权，长周期收益略偏低，教学无碍。
7. **成交量单位**：ETF 原始 volume 是「股」，但 511260 这类高价债 ETF 容易在数据源里出现手/股漂移，遇到量额不自洽的行建议用 amount/close 反推校验。
8. **已知脏行**：161129.SZ 在 20260730 出现 low(1.946) > open(1.890)，原始数据源即如此（LOF 流动性差/溢价异常），教学时可直接丢弃该行；已核对 history2 与缓存一致，不是导出错误。
9. **最新一天可能未定稿**：若在盘中导出，最后一行可能是实时快照而非收盘价；本快照取自盘后文件，已定稿。
